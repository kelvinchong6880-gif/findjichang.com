# 第 4 步：网站视觉样式

状态：已确认并锁定  
日期：2026-08-18

## 已实施的视觉方向

- 定位：专业测评媒体与清晰购买决策工具。
- 主色：深海军蓝与明亮蓝；绿色表示通过或可核验状态，橙色用于提醒。
- 字体：优先使用中国大陆设备自带中文字体，不依赖境外字体服务。
- Logo：定位标记与连接节点组成的轻量网页图形，搭配“找机场”文字标志。
- 页面：浅色背景、克制阴影、清晰卡片和充足留白，避免霓虹与廉价广告感。
- 转化：蓝色主按钮与白色次按钮并用；推广关系在注册入口附近说明。
- 数据：未知价格、速度和解锁能力统一显示“待核验”或“待补充”。

## 已完成页面

- 正式首页：价值说明、选择流程、信任原则、重点品牌、按需求选择和资料方法。
- 桌面与手机导航。
- 品牌列表卡片。
- 36 个品牌测评页面模板。
- 36 个品牌测速资料页面模板。
- 响应式页脚与推广披露。
- 网站分享封面与基础社交分享信息。

## 响应式规则

- 手机端使用折叠菜单。
- 卡片在窄屏切换为单列。
- 数据指标在手机端使用两列。
- 正文与按钮保持适合触控的尺寸。
- 不使用自动弹窗或遮挡正文的悬浮广告。

## 本步骤边界

本步骤只建立视觉系统和页面模板，没有撰写 72 篇正式内容，也没有添加未经核验的价格或测速数据。
