# 第 8 步：转化追踪与数据分析

状态：已确认并锁定  
日期：2026-08-18

## 指标分层

1. Bing Webmaster Tools：展现、点击、CTR、排名、查询、抓取与 AI 引用。
2. Cloudflare Web Analytics：页面访问、来源、地区和性能。
3. 找机场第一方出口：品牌注册链接点击，只代表注册意向。
4. 各品牌推广后台：真实注册、付费和佣金；后台没有的数据保持空白。

## 匿名出口事件

统一出口为 `/go/{brand}/`。只允许记录品牌代号、来源页面、按钮位置和 UTC 日期；不记录姓名、电话、邮箱、完整 IP、账号、设备指纹或用户输入。出口返回 302、禁止缓存，并使用 no-referrer 跳转到品牌推广链接。

按钮位置固定为 hero、summary、pricing、sidebar、article-end、recommend-card、comparison-table 和 mobile-bottom。无效品牌返回 404；无效来源或位置归为 unknown。

Cloudflare Analytics Engine 绑定名称规划为 `CLICK_EVENTS`。没有绑定时仍能正常跳转，但不会伪造数据。实际资源在 Cloudflare 部署阶段创建。

## 分析与验证配置

Cloudflare Web Analytics Token 与 Bing 验证码均通过环境变量配置。留空时不加载分析脚本、不输出虚假验证码。第一版不安装 Microsoft Clarity、会话录像或设备指纹工具。

## 链接健康

36 个品牌均具有链接状态和最后检查日期字段。上线前需要逐项核验；未检查、失效或跳转异常的链接不得标记为有效。

## 每周检查

- Bing 展现、点击、CTR、抓取错误与新增收录页面。
- 点击最多的页面、品牌和按钮位置。
- 失效推广链接和异常跳转。
- 新发布或更新内容的 IndexNow 与收录状态。

## 每月检查

- 各品牌出口点击、后台注册、付费和佣金。
- 点击到注册、注册到付费转化率；只有分子与分母均真实存在时才计算。
- 测评、测速、推荐和对比等内容类型的转化表现。
- Bing 查询、落地页、AI 引用和需要更新的资料。

## 隐私原则

采用数据最小化，不建立跨站或个人用户画像。推广披露与隐私政策明确区分点击、注册和付费，说明跳转后适用第三方条款。
