# 第 6 步：Bing 优先的分类与发布规则

状态：已确认并锁定  
日期：2026-08-18

## 1. 固定内容类型

全站固定为推荐、测评、测速、教程、知识和对比六类，不允许作者随意新增一级栏目。品牌、设备、客户端、场景和线路属于结构化字段，首版不生成自由标签页。

## 2. 文件与代号

测评、测速、教程、知识和对比分别保存在对应内容目录。文件名只允许小写英文字母、数字与短横线，不含年份、空格或中文。品牌字段必须使用品牌资料库的唯一代号。

## 3. 分类选项

- 设备：Windows、macOS、Android、iOS、路由器。
- 客户端：Clash Verge、Mihomo Party、sing-box、Shadowrocket、Surge、v2rayNG。
- 场景：预算、稳定、低延迟、流媒体、AI、游戏、大流量、新手。
- 线路：直连、中转、IPLC、IEPL、未知；无法验证时必须使用“未知”。

## 4. Bing 发布门槛

每篇文章必须通过：搜索意图、原创附加价值、事实核验、来源归属、自然语言、推广披露、标题层级、图片替代文字、内部链接、结构化数据一致性、内容厚度和日期准确性十二项检查，并完成编辑复核。

AI 可以辅助整理与起草，但不能在无人复核的情况下批量发布。第三方资料必须增加交叉核验、限制说明、统一维度解释或其他原创价值，禁止复制、拼接和轻度改写竞争页面。

## 5. 收录控制

当前网站处于开发阶段，全站暂时输出 `noindex, follow`。72 个品牌骨架页不会作为正式内容提交。只有内容达到发布标准、站点准备上线并人工开启收录后，合格页面才可进入 Sitemap 和 IndexNow 提交队列。

robots.txt 不阻止 Bingbot 访问页面，因为 Bing 需要抓取页面才能识别 noindex。草稿、研究中、事实核验中和薄内容页面不进入 Sitemap。

## 6. 排序与关联

栏目列表优先展示已发布内容，再按品牌优先级和真实更新时间排序。测评与测速必须双向关联；对比必须关联两个合法品牌；教程和知识只关联真正相关的品牌或内容。

## 7. 前 0～5 步 Bing 审计

### 已符合

- 定位强调可验证依据、编辑独立和推广披露。
- 关键词按搜索意图归组，没有为每个近义词制造独立页面。
- URL 简短、稳定、无年份，并设置 canonical。
- 自由标签和搜索参数页不开放收录。
- 普通 HTML 链接、语义化标题、移动端布局和清晰导航已经建立。
- 第三方来源、采集日期、测试环境、交叉核验和更正记录已经结构化。
- 推广链接使用 sponsored、nofollow 和 noopener。
- 内容计划反对虚构数据、关键词堆砌和一次性批量发布。

### 本步骤已补强

- 为开发期全站增加 noindex，避免 72 个空骨架被收录。
- 增加 Bing 质量检查字段与编辑复核字段。
- 把真实发布日期与创建日期分开，避免未发布草稿产生虚假发布日期。
- 建立固定分类选项和文件名规则。
- 增加可抓取的 robots.txt，不错误阻止 Bingbot。

### 后续步骤必须完成

- 正式 XML Sitemap 与准确 lastmod。
- IndexNow，只提交新增、更新和删除的合格 URL。
- Article、BreadcrumbList 等与可见正文一致的结构化数据。
- 真实的 404、301 和内容撤回规则。
- Bing Webmaster Tools 域名验证与上线后报告检查。
- 每篇正式文章的独立标题、描述、来源、图片说明及人工质量验收。

## 8. 上线原则

宁可先发布少量证据充分、内容独立的文章，也不一次上线大量相似、自动生成或资料不完整的页面。
