# 第 3 步：分类、URL 与全站信息架构

状态：已确认并锁定  
日期：2026-08-18

## 1. 设计目标

- 新手进入网站后能快速理解“找机场”提供什么。
- 测评、测速资料、推荐、教程和知识内容各有清楚入口。
- 每个品牌的测评页与测速资料汇总页互相链接。
- URL 简短、稳定，不因标题或年份变化而变化。
- 支持超过 100 篇内容继续扩展。
- 避免分类、标签和搜索页制造大量重复页面。

## 2. 主导航建议

桌面端主导航控制为 6 个主要入口：

1. 首页
2. 机场推荐
3. 机场测评
4. 机场测速
5. 使用教程
6. 机场知识

右侧设置明显但不过度夸张的“查看推荐”按钮，进入机场推荐页。

移动端使用折叠菜单，保持相同顺序。

## 3. 一级页面与 URL

### 首页

- URL：`/`
- 作用：品牌说明、重点推荐、热门测评、最新测速资料、新手入口和信任说明。

### 机场推荐

- URL：`/recommend/`
- 主关键词方向：机场推荐、稳定机场、便宜机场、机场怎么选。
- 作用：按需求、预算和使用场景帮助用户选择。

未来可扩展：

- `/recommend/budget/`：低预算选择
- `/recommend/stable/`：稳定性优先
- `/recommend/streaming/`：流媒体场景
- `/recommend/ai/`：AI 工具场景

这些子页面只有在有足够独立内容时才创建，第一版不批量生成。

### 机场测评

- 汇总页：`/jichang/`
- 品牌页：`/jichang/{slug}/`
- 示例：`/jichang/weifeng/`
- 页面数量：36 个品牌测评页。

每个品牌测评页承接：

- 品牌名 + 机场
- 品牌名 + 怎么样
- 品牌名 + 好用吗
- 品牌名 + 测评
- 品牌名 + 官网
- 品牌名 + 优惠码
- 品牌名 + 套餐价格
- 品牌名 + 稳定吗
- 品牌名 + 跑路了吗

### 机场测速

- 汇总页：`/speed-test/`
- 品牌页：`/speed-test/{slug}/`
- 示例：`/speed-test/weifeng/`
- 页面统一类型：找机场测速资料汇总
- 页面数量：36 个品牌测速资料页。

每个测速资料页承接：

- 品牌名 + 机场测速
- 品牌名 + 速度测试
- 品牌名 + 节点测速
- 品牌名 + 晚高峰测速
- 品牌名 + ChatGPT 解锁
- 品牌名 + Netflix 解锁

### 使用教程

- 汇总页：`/guide/`
- 文章页：`/guide/{slug}/`

内容范围：

- Windows、macOS、Android、iOS 使用教程
- 客户端安装和配置
- 订阅导入和更新
- 常见连接问题
- 新手注册与购买流程

不在 URL 中继续嵌套设备分类，以免层级过深。设备类型作为内容字段和页面筛选条件。

### 机场知识

- 汇总页：`/knowledge/`
- 文章页：`/knowledge/{slug}/`

内容范围：

- 行业术语
- 套餐和流量解释
- 延迟、丢包、倍率和带宽
- 测速方法
- 风险、退款和隐私知识
- 如何辨别官网和失效链接

### 对比内容

- 汇总页：`/compare/`
- 文章页：`/compare/{slug}/`
- 示例：`/compare/weifeng-vs-firefly/`

对比页不放入第一层导航，主要通过机场推荐页、品牌页和站内链接进入。

## 4. 信任与法律页面

统一放在页脚：

- `/about/`：关于找机场
- `/contact/`：联系我们
- `/methodology/`：评测与测速资料方法
- `/affiliate-disclosure/`：推广披露
- `/privacy/`：隐私政策
- `/terms/`：使用条款
- `/disclaimer/`：免责声明

## 5. 内容关联规则

每个品牌至少形成下面的关系：

`品牌测评页 ↔ 品牌测速资料汇总页`

同时：

- 测评页链接到推荐页和相关教程。
- 测速页链接回测评页和测速方法页。
- 推荐页链接到入选品牌的测评页。
- 对比页链接到双方品牌测评页和测速页。
- 教程页根据使用的客户端链接到相关知识文章。

## 6. 分类与标签原则

- 一级内容类型固定为：推荐、测评、测速、教程、知识、对比。
- 品牌、设备、客户端、使用场景作为结构化字段。
- 第一版不生成可收录的自由标签页。
- 如果以后开放标签页，只有拥有至少 3 篇高质量内容的标签才允许收录。
- 站内搜索结果页不允许搜索引擎收录。

## 7. 面包屑示例

- 首页 > 机场测评 > 微风机场测评
- 首页 > 机场测速 > 微风机场测速资料汇总
- 首页 > 使用教程 > Windows 客户端安装教程
- 首页 > 机场对比 > 微风与 Firefly 对比

## 10. 实施结果

- 已建立 6 项主导航和 7 个页脚信任/法律入口。
- 已建立 36 个品牌资料记录，推广链接集中维护。
- 已自动生成 36 个品牌测评路由和 36 个品牌测速资料路由。
- 每个品牌测评页与测速资料页已双向关联。
- 已建立推荐、教程、知识和对比汇总页骨架。
- 已建立测评、测速、教程、知识和对比的内容集合字段约束。
- 测速资料来源字段要求记录来源网址与采集日期。
- 第三方推广链接统一使用 `sponsored nofollow noopener` 属性。
- 未生成自由标签页和搜索结果页，避免首版出现低价值可收录页面。
