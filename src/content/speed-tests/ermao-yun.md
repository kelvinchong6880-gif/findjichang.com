## 当前6种套餐

用户提供的登录后官网资料显示，二猫云当前包含1个年付小包、4个常规月付档和1个不限时流量包：

| 套餐 | 当前价格 | 流量规则 |
| --- | ---: | ---: |
| 二猫年付小包 | 89元/年 | 每月60GB |
| 白猫套餐 | 20元/月 | 每月130GB |
| 橘猫畅玩版 | 40元/月 | 每月230GB |
| 牛奶猫尊享版 | 80元/月 | 每月430GB |
| 黑猫重度用户版 | 160元/月 | 每月850GB |
| 100G不限时套餐 | 99元/次 | 总量100GB，长期有效 |

常规套餐写明不限速、不限设备、每30天刷新流量，并提供月付、季付、半年付和年付等周期；年付小包只按年购买。官网还列出年付8折、两年付7折、三年付6折，但本文没有进入最终结算页核对各周期实付金额，因此不计算折后价。

100G不限时套餐是一次性购买的**总流量包**：长期有效、用完为止，并可后续补充流量。它不是每月100GB，也不是无限流量。

## 官网详情存在两处价格残留

橘猫畅玩版卡片的Current Offer是40元/月，牛奶猫尊享版是80元/月，但两张详情文案仍残留“20元/月”。本文采用Current Offer和套餐标题附近的价格，不采用残留文案；实际付款前仍应在订单确认页检查金额。

旧的2026年4月资料曾记录白猫100GB、橘猫200GB、牛奶猫400GB和黑猫800GB。当前官网已分别变为130GB、230GB、430GB和850GB，旧数字只能用于说明套餐曾发生变化。

## 套餐宣传不等于测速证据

官网宣传全IEPL、单节点峰值2.5Gbps、晚高峰不降速、原生IP、智能路由、不限设备，以及Netflix、Disney+、ChatGPT和TikTok解锁。节点地区包括香港、台湾、日本、新加坡和美国等。

这些是服务方描述。没有当前订阅清单、入口和出口路由、节点IP检测及带宽监控，本站不能确认全部节点都使用IEPL，也不能把2.5Gbps峰值理解为每位用户的保证速度。

| 项目 | 来源汇总结果 |
| --- | ---: |
| 完成节点 | 40/40 |
| 香港节点中位速度 | 93.32MB/s，约747Mbps |
| 香港节点中位延迟 | 36ms |

全节点完成率和地区中位数比只展示最快节点更有参考价值。不过仓库当前返回404，本站没有取得40个节点逐项表、测试日期、上传、丢包、失败重试、客户端参数和未修改原图，无法复算93.32MB/s，也不能外推到联通、移动或今天的表现。

## 三网图片有入口，结构化数据不足

翻翻墙社区2026年4月帖子提供线路分析，以及中山电信、陕西联通、辽宁移动三条1Gbps单线程测速图片入口。它覆盖三家运营商，方向正确，但正文没有列出测试时间、客户端、节点名称、逐项速度或标准丢包。

帖子位于“官方评测”板块，机场介绍没有主观点评，图片来源和服务商关系也不清楚。因此本文确认这些图片入口存在，但不从图片外观推导平均速度或“跑满千兆”的结论。

## 两组推广测速只能作历史样本

VPS Rank称2026年4月使用北京联通2Gbps、Wi-Fi 6路由器和多台设备测试。其Speedtest表中五地区下载为350至380Mbps、上传50至60Mbps、延迟100至200ms；Fast.com表中下载为370至980Mbps。两种工具差异较大，且页面没有公开测试结果ID或未修改原图，因此不能合并求平均。

另一个推广页面称2026年5月21:00使用电信1000M和专属客户端或Clash Verge Rev，五地区下载650至920Mbps、上传95至160Mbps。数据随地区整齐下降，页面同时给出4.9/5评分和绝对化宣传，缺少原始链接，本文将其降级为待复核资料，不用来证明“晚高峰坚如磐石”。

## 流媒体、AI和客户端仍需逐节点核验

5月推广表称Netflix在台湾、香港、新加坡可用，ChatGPT在日本、美国、台湾可用，Disney+在新加坡、台湾可用。这个结果本身说明解锁具有地区差异，不能写成所有节点全平台成功。

第三方资料对客户端也有冲突：一份2026年4月资料称当时关闭通用订阅、只能使用自研客户端，较新的推广资料又称支持Clash等通用客户端。实际支持范围应以用户登录后的下载页和客服书面回复为准。

## 当前结论与后续验证

二猫云当前最低月付为20元130GB，另有89元年付小包和99元100GB不限时包。公开晚高峰汇总的40/40节点与93.32MB/s香港中位速度具有一定参考价值，但原始仓库失效；三网社区图和两组推广测速也不足以形成长期稳定结论。

后续应取得有效订阅和完整节点清单，在同一设备、客户端和测速服务器上，分别用电信、联通、移动测试白天及20:00至23:00，保留下载、上传、延迟、标准丢包、失败节点、逐节点解锁和未修改原图。证据补齐前，不生成“找机场实测”评分或全IEPL达标结论。
