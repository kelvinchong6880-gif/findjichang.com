## 当前套餐概览

用户提供的登录后购买订阅页截图可确认7种套餐：

| 套餐 | 价格与周期 | 流量规则 |
| --- | ---: | --- |
| 轻量版 | 99元/年 | 每月59GB |
| 极速版 | 23元/月 | 每月138GB |
| 流光版 | 34元/月 | 每月220GB |
| 量子版 | 68元/月 | 每月450GB |
| 无界版 | 130元/月 | 每月900GB |
| 不限时套餐 | 680元/次 | 总量1TB，用完为止 |
| 定制套餐 | 680元/月 | 每月500GB，可按需求调整 |

极速版当前已经从第三方旧资料常见的17元/110GB变为23元/138GB；其余主要档位与旧资料接近。轻量版卡片顶部显示99元/年，但卡片正文又出现“59元/月/59G流量”，两处自相矛盾。本文采用结算卡主价格99元/年，同时保留正文冲突，购买前应再次查看结算金额。

不限时套餐是一次性1TB总流量，无到期时间且购买后不自动重置；手动重置费用写为原价90%，即612元。它不是每月1TB，也不是无限流量。定制套餐则是月付服务，截图称可提供独享原生IP、独立带宽和按地区配置，具体线路与交付仍需客服书面确认。

## 2.5Gbps和晚高峰满速属于套餐宣传

极速版至无界版的套餐卡写全节点1倍率、全球IPLC、单节点最高2.5Gbps、原生IP解锁、不限设备和“高峰满速”。轻量版另写“晚高峰依旧稳”。这些是服务方对线路和套餐上限的描述，不是用户从中国大陆到各落地节点都能达到2.5Gbps的实测保证。

套餐列出的地区包括香港、台湾、日本、新加坡、马来西亚、美国、德国、法国、英国、土耳其和越南。套餐页同时宣传Netflix、Disney+、ChatGPT和TikTok解锁；平台风控、IP归属和节点负载会变化，必须以逐节点脚本和实际登录结果为准。

## 2025年12月晚9点单次记录

Kerry的学习笔记称在本地1000Mbps宽带上，于12月23日晚9点运行全节点测速，结果“差不多50MB/s”，并表示测试只跑到本地带宽的一半左右。该页面还记录YouTube 4K 60帧播放与部分流媒体、AI服务可用，但美国节点测试曾超时。

50MB/s约等于400Mbps，是一条可参考的晚高峰吞吐记录。不过来源没有写明具体年份的图片时间戳、被测套餐、节点、运营商、测速服务器、持续时间、上传和丢包，因此不能据此宣称全节点或三网晚高峰都稳定。

## 2026年1月三网观察记录带宽不足

茶波博客提供湖南电信2Gbps、浙江联通1Gbps和陕西移动1Gbps三组测速图片入口，但正文没有逐节点数字。其2026年1月29日更新称白天速度能畅跑，晚高峰则带宽不足，并推测短期用户增长可能造成拥堵；该来源当时建议等待扩容。

这条负面记录与前述12月晚9点约50MB/s并不必然矛盾：两者可能来自不同日期、入口、套餐、节点或负载。由于没有统一环境和可复算的逐节点数据，本文不对两组结果取平均，也不将较新的负面观察删除。

## 2026年3月62节点样本显示地区分化

推荐VPN页面记录2026年3月20日使用长沙电信2Gbps、量子版和MiaoKo工具测试62个Shadowsocks节点，覆盖12个地区。其汇总数字如下：

| 地区或项目 | 来源报告结果 |
| --- | ---: |
| 香港TLS延迟 | 约30至40ms |
| 台湾、日本、新加坡延迟 | 约40至80ms |
| 美国、土耳其延迟 | 约180至300ms |
| 法国、英国、德国延迟 | 约300至400ms以上 |
| 日本节点下载 | 多数约20至36MB/s，峰值约47MB/s |
| 欧美及部分东南亚下载 | 多数约数百KB/s至1MB/s |

该样本说明“单节点最高2.5Gbps”不能代替地区和节点实测：同一次测试内，日本与欧美节点吞吐差距很大。页面还记录TikTok在台湾、新加坡、日本普遍失败，Spotify全线不能注册，欧美节点部分流媒体失败或未知；多数节点的Netflix、Disney+、YouTube和OpenAI结果较好。

这些数字来自第三方对测试图的汇总。当前页面没有说明设备、客户端版本、上传与标准丢包方法，本文只引用其报告值，不把它改写为本站实测。

## 2026年6月30天监测数字

GateRank的2026年6月月报给出截至6月30日的近30天快照：可用率100%、下载速度中位数114.29Mbps、延迟中位数3.22ms、丢包率0%，连续健康和连续稳定均只有2天，同时记录SSL告警。

3.22ms明显低于第三方海外节点TLS延迟，更可能反映监测探针到某个入口或目标的链路，而不是中国大陆用户到全部海外落地的真实延迟。该页面也未公开探针地点、目标节点、基础带宽、设备、客户端和采样方式，因此不能用这组数字证明三网晚高峰已经恢复。

## 当前结论与后续验证

光速云已有跨时间、三网和62节点的第三方资料，证据比只有套餐宣传更完整，但晚高峰表现和地区速度并不一致。2026年3月样本显示日本节点较快、欧美节点明显偏慢，也保留了TikTok、Spotify和部分欧美流媒体失败结果。

下一轮应取得有效订阅和当前节点清单，在同一设备、客户端、测速服务器与电信、联通、移动网络上分别测试白天和20:00至23:00，记录逐节点下载、上传、延迟、标准丢包、失败节点和解锁原图。完成前不生成“找机场实测”评分或稳定性保证。
