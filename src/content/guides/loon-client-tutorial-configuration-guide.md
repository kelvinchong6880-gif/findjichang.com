**引言**：提到 iOS 平台上的网络代理工具，很多人第一时间想到的是老牌的 Shadowrocket（小火箭）、高端昂贵的 Surge 或是极客范十足的 Quantumult X（圈X）。然而，近年来有一款名为 Loon 的工具异军突起，它不仅拥有媲美 Surge 的精美 UI 界面，还具备超越小火箭的强大规则与插件管理能力，同时价格亲民（买断制）。如果您觉得小火箭界面太陈旧，又觉得圈X和 Surge 配置太硬核，那么 Loon 绝对是您苹果手机上最较好的“轻量化科学上网选择”。本文将带您从零开始，玩转 Loon！

## 一、 初识 Loon：为什么它是介于小火箭与 Surge 之间的较好平衡？

> 💡 **站长提示**：开始前，请确保你拥有一个稳定解锁流媒体和 ChatGPT 的机场订阅，如果没有，推荐使用 [找机场推荐专线](/go/weifeng/?from=/guide/loon-client-tutorial-configuration-guide/&placement=article-end)。


在动手配置之前，我们先来了解一下，作为新手，为什么你应该选择 Loon？

- **极致的 UI 审美**：Loon 的界面设计语言非常贴合最新的 iOS 系统规范，毛玻璃效果、清晰的数据统计仪表盘、直观的卡片式布局，颜值在一众代理工具中名列前茅。
- **“傻瓜式”的插件系统 (Plugin)**：这是 Loon 最大的杀手锏。过去在圈X里去广告，你需要自己去复制复杂的重写脚本和链接；而在 Loon 中，各种去广告、功能解锁脚本被打包成了“插件 (Plugin)”，你只需要像在应用商店下载 App 一样，一键安装、一键开启/关闭，极其优雅。
- **出色的性能与轻量化**：Loon 占用的系统资源极低，在长时间开启后台代理的情况下，对 iPhone 电池续航的影响微乎其微。
- **性价比之选**：相比 Surge 动辄几百元的售价，Loon 采用一次性买断制（目前美区售价约 $5.99 - $7.99），非常划算。

## 二、 准备工作：如何下载安装 Loon？


众所周知，受限于政策，Loon 并没有在中国大陆区的 App Store 上架。要下载它，我们需要借助外区账号。

### 1. 准备非大陆区 Apple ID
您需要准备一个美区 (US)、港区 (HK) 或台区 (TW) 的 Apple ID。

> **⚠️ 安全警告**：如果您使用网上购买或别人分享的外区 Apple ID，请务必只在 **App Store** 登录，**绝对不要**在手机系统的“设置 -> Apple ID (iCloud)”中登录！ 否则有手机被锁死的风险。可以参考我们的 [免信用卡注册美区 Apple ID 教程](/guide/free-us-apple-id-register-complete-tutorial/)。

### 2. 购买与下载

1. 打开 iPhone 上的 **App Store**。
2. 点击右上角的个人头像，滑到最底部点击“**退出登录**”。
3. 登录您的外区 Apple ID。
4. 在搜索框搜索 **Loon**（注意图标是一个类似水滴/定位符的蓝色标志）。
5. 充值外区礼品卡（Gift Card）购买后即可下载。安装完成后，桌面会出现 Loon 的应用图标。

## 三、 核心配置第一步：导入机场节点订阅


有了工具，我们还需要“网络通道”，也就是您购买的机场服务。Loon 支持目前主流的 Shadowsocks, V2Ray (VMess/VLESS), Trojan 等协议。

### 1. 获取机场订阅链接

首先，登录您的机场官网控制台。
寻找“一键订阅”、“节点导入”或“API 订阅”选项。

由于 Loon 相对小众，如果您的机场没有直接提供“复制 Loon 订阅”的按钮，请不要慌张。Loon 兼容性极强，您直接点击“**复制通用订阅链接**”或“**复制 Shadowrocket / Surge 订阅链接**”都可以。

### 2. 在 Loon 中添加订阅

打开刚刚下载好的 Loon App，跟着以下步骤操作：
### 1. 进入配置页面点击 Loon 主界面底部的 “配置” 菜单栏。

### 2. 找到节点订阅在“节点”板块下，点击 “节点订阅”。

### 3. 添加链接
   * 点击右上角的 “+” 号。
   * **名称 (Name)**：随便起个名字，比如“我的主力机场”。
   * **URL**：将您刚才在机场后台复制的订阅链接粘贴到这里。
   * **自动更新**：建议打开，并将更新间隔设置为 24 小时，这样机场节点有变动时会自动同步。
   * 点击右上角的 “保存”。
### 4. 获取节点保存后，Loon 会自动向服务器拉取节点。回到 Loon 的首页，您会看到一条曲线图，并且在“策略组”里出现了多个国家的节点选项，这意味着节点导入成功！


### 3. 首次开启 VPN 授权
1. 在 Loon 首页，点击顶部巨大的 “未运行” 按钮（或右上角的开关）。
2. 系统会弹出提示：“Loon Would Like to Add VPN Configurations”。
3. 点击 “Allow (允许)”，并输入手机密码或验证 Face ID。
4. 手机状态栏出现 **[VPN]** 标识，网络通道已打通！

## 四、 智能网络的大脑：理解并设置分流规则与策略组


如果只是全局代理，那您访问国内网站会非常慢。我们需要让 Loon 变聪明：国内直连，国外走节点，广告直接拦截。

### 1. 什么是策略组 (Policy)？
策略组就像是节点的“文件夹”。在 Loon 的首页，您会看到不同的方块。
- **PROXIES (代理)**：里面装满了您的机场节点。您可以手动点击选择用哪个国家的节点。
- **AUTO (自动/延迟测试)**：Loon 会自动测试这个组里所有节点的延迟，并自动把流量切换到最快的那条线路上。这是建议新手使用的模式。

### 2. 导入第三方“懒人分流规则”

自己手写规则太痛苦了，我们直接站在巨人的肩膀上，使用开源社区维护好的规则库。

1. 点击底部 “配置” -> 找到“规则”板块下的 **“规则集 (Rule Set)”**。
2. 点击右上角 “+” 添加规则集。
3. 推荐使用神机规则或 blackmatrix7 规则，这里提供最核心的三个：
   *   **去广告规则 (Reject)**: URL 填入开源的广告拦截规则链接，策略选择 `REJECT`（拒绝）。
   *   **国际流媒体 (Proxy)**: 比如 Netflix, YouTube 的规则，策略选择您的 `PROXIES` 或 `AUTO` 组。
   *   **国内直连 (Direct)**: 国内常用网站规则，策略选择 `DIRECT`（直连）。

> *(注：优质机场通常会在订阅中自带基础的分流规则，如果您发现导入节点后已经可以实现国内快、国外通，这一步可以跳过。)*

## 五、 Loon 的灵魂功能：插件 (Plugin) 与高级重写

这是 Loon 碾压小火箭的核心优势。什么是插件？简单来说，通过插件，你可以解锁 TikTok 区域限制、去除某些国内毒瘤 App 的开屏广告、甚至修改 App 的本地主题颜色。

### 如何使用 Loon 插件？
1. 点击底部菜单栏的 “插件”。
2. 点击右上角的 “+”。
3. 此时您可以输入插件的 URL 链接（许多开发者在 Github 和 Telegram 上分享 Loon 插件）。
4. 添加后，插件列表中会出现对应的卡片，您只需要拨动开关即可启用或停用该功能。

> **极其优雅的交互**：与圈X密密麻麻的代码不同，Loon 的插件界面带有图标、功能描述、甚至作者信息，对于非技术人员极其友好。

## 六、 进阶必修：配置 MitM (中间人) 证书


如果您想要上面提到的“插件”真正发挥作用（特别是涉及去广告和修改 App 数据的插件），您就必须配置 MitM 证书。因为现在所有的 App 都是 HTTPS 加密传输，Loon 需要一张证书才能“看懂”并修改这些流量。

### 保姆级 MitM 配置步骤：


### 1. 生成证书
   * 点击 Loon 底部 “配置” -> 找到 “MITM” 卡片点击进入。
   * 点击 “生成证书”。
### 2. 下载与安装证书

   * 点击 “安装证书”，系统会跳转到 Safari 浏览器并下载一个配置描述文件。
   * 回到 iPhone 系统的自带 “设置” App，点击最上方的“已下载描述文件”，一路点击“安装”并输入手机密码。
### 3. 信任证书（最关键一步）
   * 在 iPhone “设置”中，依次进入：**通用 -> 关于本机 -> 证书信任设置**（滑动到最底下）。
   * 找到 `Loon Custom Root Certificate`，将其开关打开变绿，并在弹出的警告中选择“继续”。
### 4. 开启 MitM
   * 回到 Loon App 内，将刚才 MITM 页面最上方的 **开关** 打开。

完成这四步，您的 Loon 就拥有了“上帝视角”，搭配各种神仙插件，体验直接拉满！

## 七、 常见问题排障指南 (FAQ)

### Q1: 节点全部变红（显示超时），无法上网怎么办？
- **检查1**：确认 Loon 首页最顶部的总开关是否处于开启状态。
- **检查2**：登录您的机场控制台，检查套餐是否过期、流量是否用尽。
- **检查3**：在 Loon 首页，下拉刷新一下节点延迟。如果是单一节点挂了，切换到其他国家节点；如果全部挂了，尝试在“节点订阅”里左滑订阅链接，点击“更新”。

### Q2: 为什么我访问国内的淘宝、抖音感觉加载变慢了？
- 这通常是因为“全局路由”设置错误。请在 Loon 首页点击右下角的模式切换按钮，确保当前处于 **“规则分流 (Rule)”** 模式，而不是“全局代理 (Global)”。全局代理会让所有国内流量也绕道国外，导致严重卡顿。

### Q3: 开启 MITM 证书后，某些银行 App 提示网络风险无法登录？
- 银行和金融类 App 安全级别极高，会检测到证书被劫持。解决办法是：在 Loon 的 MITM 设置中，找到“跳过主机名 (Skip Hostnames)”，将银行 App 相关的域名加进去，或者干脆在操作网银时临时关闭 Loon。
