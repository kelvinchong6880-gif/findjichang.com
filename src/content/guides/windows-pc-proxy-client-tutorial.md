## 一、核心概念科普：搞懂订阅与客户端


很多刚接触网络加速的新手经常混淆“机场服务”与“代理软件”的关系。我们可以将其拆解为以下核心模块：

### 1. 节点服务器（Server）部署在香港、日本、新加坡、美国等地区的云服务器，负责中转网络流量。
### 2. 订阅链接（Subscription URL）机场服务商提供的一串加密网址（或 API 接口），其中打包了数十至数百个节点服务器的连接参数（协议、端口、密钥、加密算法等）。

### 3. 代理客户端（Client GUI）运行在 Windows 系统本地的图形化工具（如 Clash Verge Rev、v2rayN），负责解析订阅链接中的节点，并控制电脑流量分流。


> **形象比喻**：
> 客户端好比一台**播放器**，订阅链接好比**视频播单**。光有播放器看不了视频，光有播单没有播放器也无法解码。两者结合，才能畅快观影。

## 三、方案一：Clash Verge Rev 极速配置指南（最推荐）


**Clash Verge Rev** 是目前在 Windows 平台最受欢迎的开源客户端，UI 美观优雅，功能模块清晰，且深度整合了 Clash Meta（Mihomo）内核。

---

### 1. 软件下载与安装


1. 前往官方 GitHub Releases 仓库或从本站提供的客户端下载中心获取最新安装包。
2. Windows 64位系统用户请选择形如 `Clash.Verge_x.x.x_x64_zh-CN.msi` 或 `x64-setup.exe` 的安装程序。
3. 双击安装包，建议安装到非系统盘默认路径，勾选“创建桌面快捷方式”。

---

### 2. 界面汉化与基础设置


打开软件后，Clash Verge Rev 默认即为简体中文界面。若显示英文，可进行如下调整：

- 点击左侧导航栏的 **「Settings（设置）」**。
- 找到 **「Language（语言）」**，下拉切换为 `简体中文`。
- 将 **「Clash 内核（Clash Core）」** 确认为 `Mihomo (Clash.Meta)`，以确保获得对最新网络协议的兼容支持。

---

### 3. 一键导入机场订阅


导入节点订阅通常有两种方式：

#### 方式 A：一键导入（最便捷）
1. 登录你的机场后台用户中心。
2. 找到 **「一键导入」** 或 **「快捷导入」** 区域，点击 **「导入到 Clash / Clash Verge」**。
3. 浏览器会自动拉起本地客户端，点击确认保存即可。

#### 方式 B：手动复制订阅链接
1. 在机场后台复制 **「Clash 订阅链接 / 节点链接」**。
2. 打开 Clash Verge Rev，点击左侧菜单栏的 **「订阅 (Profiles)」**。
3. 在顶部输入框粘贴刚才复制的链接，点击右侧的 **「下载 (Download)」** 按钮。
4. 待下载进度完成，界面将显示订阅卡片，**鼠标左键单击该卡片**（卡片变高亮/出现勾选状态），即代表当前激活该订阅。

---

### 4. 选择节点与开启系统代理

1. 点击左侧导航栏的 **「代理 (Proxy)」**。
2. 展开 **「PROXY / 节点选择」** 分组，点击右下角的 **「延迟测速（闪电图标）」**，系统会自动对所有节点进行 Ping 测试。
3. 选择一个绿色低延迟、低丢包率的节点（如 `香港 01` 或 `新加坡 02`）。
4. 返回左侧导航栏的 **「设置 (Settings)」**，打开 **「系统代理 (System Proxy)」** 开关。
5. 此时打开浏览器访问 `Google` 或 `YouTube`，即可正常浏览。

---

### 5. 进阶玩法：开启 TUN 模式（全流量与游戏代理）


常规的“系统代理”仅接管遵循系统代理规范的浏览器及部分应用软件流量。如果你需要为**CMD命令行、Git终端、Discord桌面版、Steam外服游戏、Epic客户端**等不走系统代理的应用提供全流量中转，需开启 **TUN 模式**。

### 1. 安装服务模式进入「设置」页面，找到「服务模式 (Service Mode)」，点击右侧「安装 (Install)」，安装完成后图标将变为绿色激活状态。

### 2. 开启 TUN 模式在「设置」中找到 **「Tun 模式 (Tun Mode)」**，将开关切换为开启。

### 3. 效果Windows 系统网络连接中会自动生成一个虚拟网卡，强制接管整机所有 TCP/UDP 流量。

## 四、方案二：v2rayN 经典客户端配置指南（轻量与多协议）


对于追求极低内存占用、喜欢原生快捷键托盘操作的用户，**v2rayN** 是历经多年检验的经典工具。

---

### 1. 核心与客户端下载


1. 下载 v2rayN 完整包（建议选择包含 Core 核心的 `v2rayN-with-Core.zip` 压缩包）。
2. 解压到无中文字符、无空格的本地磁盘路径（例如 `D:\Software\v2rayN\`）。
3. 进入文件夹，双击运行 `v2rayN.exe`（托盘区会出现蓝色或红色小图标）。

---

### 2. 订阅分组添加与更新


1. 复制机场后台提供的 **「v2ray 订阅」** 或 **「通用订阅」** 链接。
2. 打开 v2rayN 主界面，点击顶部菜单栏 **「订阅分组 (Subscription)」** -> **「订阅分组设置」**。
3. 点击 **「添加」**：
   - **别名**：输入你的机场服务名称（如 `我的机场`）。
   - **可选地址 (URL)**：粘贴订阅链接。
4. 点击底部 **「确定」** 保存。
5. 回到主菜单，点击 **「订阅分组」** -> **「更新全部订阅（不通过代理）」**，下方节点列表将刷新出所有可用服务器。

---

### 3. 路由规则与系统代理切换


1. 在底部控制面板中，将 **「路由 (Routing)」** 设置为 `绕过大陆 (bypass cn)` 或 `黑名单 (Blacklist)`，确保国内网站直连不消耗节点流量。
2. 在节点列表中选中想要使用的节点，按键盘 `Enter` 键或右键选择 **「设为活动服务器」**。
3. 鼠标右键点击 Windows 任务栏右下角托盘区的 v2rayN 小图标：
   - 找到 **「系统代理」**，选择 **「自动配置系统代理」**（图标变红，代表代理已生效）。
4. 不需要使用时，右键选择 **「清除系统代理」** 即可。

## 六、分流模式详解：规则、全局与直连的区别


在使用 Windows 代理客户端时，我们通常会在界面上看到三种分流模式：

                ┌─────── 访问 国内网站 (如百度/淘宝) ──────> [直连Direct] ──> 本地宽带直达
                │
用户访问流量 ──────> 规则判断(Rule)
│
└─────── 访问 海外网站 (如Google/GitHub) ──> [代理Proxy] ──> 节点服务器中转


### 1. 规则模式（Rule / PAC / 绕过大陆）- 【强烈推荐】

   - **机制**：客户端内置域名与 IP 规则库。访问国内服务（如百度、网易云音乐、微信、Bilibili）走本地直连，不消耗代理流量；访问被墙服务（如 Google、YouTube、Twitter、ChatGPT）走代理。
   - **适用场景**：日常长期挂机，完全无需手动切换。

### 2. 全局模式（Global）

   - **机制**：电脑的所有网络请求一律通过节点服务器发出。
   - **适用场景**：调试海外特定网页、查询本地节点出口真实 IP、部分规则库未覆盖的冷门海外站点。
   - **注意**：访问国内软件速度可能变慢，且会浪费机场流量。

### 3. 直连模式（Direct）

   - **机制**：跳过所有代理通道，等同于未开启代理软件。
   - **适用场景**：需要彻底排查网络环境或进行大文件国内下载时使用。

## 七、Windows 常见网络故障与错误排查大全（必看）

使用过程中如果遇到网络异常，请按照以下方案自查，99% 的常见报错均可迎刃而解：

---

### 问题 1：软件关闭后，电脑无法上网（QQ能上但网页打不开）

* **原因分析**：这是 Windows 最常见的问题。直接关闭客户端窗口并没有退出后台进程，或客户端意外闪退导致 **Windows 系统代理残留**。
* **解决方法**：
  1. 按下快捷键 `Win + i` 打开系统设置。
  2. 进入 **「网络和 Internet」** -> **「代理」**。
  3. 检查 **「手动设置代理」** 下的 **「使用代理服务器」** 是否处于开启状态。
  4. 手动将其切换为 **「关」**，即可立即恢复正常网络浏览。

---

### 问题 2：导入订阅提示“网络错误”、“500”或“下载配置文件失败”


* **排查步骤**：
  1. 检查复制的订阅链接是否完整，有无多余的前后空格。
  2. 尝试不挂代理在浏览器直接访问该订阅 URL，看是否能正常下载配置文件文本。
  3. 检查电脑系统时间是否准确：Windows 右下角时间若与国际标准时间偏差超过 90 秒，会导致 SSL 握手失败，在「时间和语言」设置中点击「立即同步」即可修复。
  4. 检查是否开启了第三方杀毒软件（如 360 安全卫士、火绒），可暂时添加客户端至信任白名单。

---

### 问题 3：节点全红、延迟显示“Timeout / 超时”或“-1”

* **排查步骤**：
  1. 登录机场后台查看账户**套餐是否过期**或**流量是否耗尽**。
  2. 本地宽带运营商 DNS 污染：进入客户端 DNS 设置，将 Remote DNS 设置为公共安全 DNS（如 `8.8.8.8` 或 `1.1.1.1`）。
  3. 点击订阅卡片右侧的「刷新」按钮，获取服务商更新后的最新服务器节点。

---

### 问题 4：开启代理后，ChatGPT / Netflix 提示“Access Denied”或“代理检测报错”


* **排查步骤**：
  1. 切换不同区域的节点（推荐选择新加坡、日本、美国原生住宅/原生 IP 节点）。
  2. 开启浏览器的无痕窗口（隐身模式）重试，清理本地 Cookie 缓存。
  3. 检查分流规则是否将 OpenAI 相关域名分流到了不支持该服务的节点（如香港节点通常无法直接访问 ChatGPT）。

## 八、总结与安全使用规范

配置 Windows 电脑端代理并不复杂，关键在于**选择维护活跃的现代化客户端**（如 Clash Verge Rev），并熟练掌握**分流模式**与**系统代理开关**。

### 安全使用温馨提示：
### 1. 警惕第三方修改版客户端务必从 GitHub 官方 Release 页面下载客户端，切勿从不明网盘或第三方论坛下载被注入后门的破解版。

### 2. 定期更新订阅配置节点 IP 和路由规则库会动态更新，建议每周至少在客户端中手动点击一次「更新订阅」。

### 3. 合规使用网络请遵守当地法律法规，科学上网仅限用于海外学术查阅、开源技术学习及外贸跨境业务用途。
