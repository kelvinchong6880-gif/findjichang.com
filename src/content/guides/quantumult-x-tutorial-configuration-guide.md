在 iOS 平台的网络代理工具生态中，我们常说的“三大金刚”分别是 Shadowrocket（小火箭）、Surge 以及今天的主角 Quantumult X（由于其图标为彩色且以 X 结尾，国内玩家亲切地称其为“圈X”）。

- **极佳的 UI 设计与交互体验**：相比于 Surge 复杂的纯文本配置和 Shadowrocket 略显陈旧的界面，圈X 提供了极具科技感且直观的图形用户界面（GUI），所有的节点状态、策略组延迟都一目了然。

- **强大的重写 (Rewrite) 与 MitM 功能**：不仅能用于科学的网络访问，圈X 还可以通过脚本（JavaScript）修改本地网络请求，实现去广告、解除部分 App 地区限制、甚至解锁某些本地高级功能。
- **性价比极高**：Surge 价格高昂（接近百美元），而 Quantumult X 采用买断制，价格适中，功能却足以媲美甚至在某些脚本玩法上超越 Surge。

## 二、 准备工作：下载与安装 Quantumult X


由于众所周知的原因，Quantumult X 并未在中国大陆区的 App Store 上架。因此，在配置之前，我们需要完成软件的获取。

### 1. 准备非大陆区 Apple ID
您需要一个美区 (US)、港区 (HK) 或台区 (TW) 的 Apple ID。如果您还没有，可以参考我们的教程 [免费注册美区 Apple ID](/guide/free-us-apple-id-register-complete-tutorial)。

> **注册建议**：强烈建议不要在网上随便使用他人分享的免费 Apple ID，以免由于 iCloud 同步机制导致您的 iPhone 被锁（变砖）。您可以自己通过 Apple 官网注册一个美区账号，或者在可靠的渠道购买一个独享账号。
>
> **⚠️ 注意事项**：登录外区账号时，请只在 App Store 登录，**千万不要在手机的“设置 -> iCloud”中登录**！

### 2. 购买并下载 App

1. 打开 iPhone 上的 **App Store**。
2. 点击右上角的头像，滑到最底部点击“**退出登录**”。
3. 输入您的美区/港区 Apple ID 并登录。
4. 在搜索框中输入 **Quantumult X**。
5. 该软件为付费软件（目前美区售价约为 $7.99），您可以通过购买美区 App Store 礼品卡（Gift Card）进行充值后购买。
6. 下载完成后，您的桌面上会出现一个带有彩色 X 的图标，这证明第一步已经大功告成。

## 三、 新手入门第一阶段：基础配置与导入机场订阅节点


对于 90% 的用户来说，使用圈X的最初目的就是为了连接网络。这里需要用到您购买的机场服务。以下是具体操作：

### 1. 获取机场订阅链接

首先，登录您的机场官网后台。找到类似“一键订阅”、“节点配置”的选项。大部分优质机场都会提供专用的 Quantumult X 订阅链接。

点击 **“复制 Quantumult X 订阅”**。

> 如果您的机场没有专门的圈X订阅，复制通用的 SSR/V2Ray/Trojan 订阅链接（URI格式）也是可以的，圈X 具备良好的向下兼容性。

### 2. 在圈X中导入节点订阅

现在，我们打开刚才下载好的 Quantumult X App。

### 1. 进入设置点击 App 主界面右下角的 “大风车” 图标，进入详细设置页面。

### 2. 找到节点模块在“节点”这一栏下，点击 “引用 (URI)”。
### 3. 添加订阅

   * 点击右上角的 “+” 号。
   * **标签 (Tag)**：随便填，比如填入您机场的名字。
   * **资源路径 (URL)**：将您刚刚在机场后台复制的订阅链接粘贴在这里。
   * **勾选配置**：建议开启“自动更新”(Auto Update)，并将更新时间设置为 24 小时。
   * 点击右上角的 “保存”。
### 4. 获取节点保存后，圈X会自动从服务器下载节点信息。如果顺利，您会在主界面的节点列表里看到一长串来自世界各地的服务器（如香港、日本、美国等）。


### 3. 测试与开启

1. 返回圈X主界面，点击右上角的 **“开关” 按钮**。
2. 第一次开启时，系统会弹出提示：“Quantumult X Would Like to Add VPN Configurations”。
3. 点击 **“Allow (允许)”**，并输入您的手机锁屏密码或使用 Face ID 进行授权。
4. 此时，手机状态栏会出现 **[VPN]** 图标，恭喜您，基础的网络连接已经建立成功！您可以尝试打开 Google 或 YouTube 测试速度。

## 四、 进阶核心：Quantumult X 策略组与分流规则解析


如果仅仅是全局开启代理，那么您访问国内网站（如淘宝、微信）也会绕道国外，这不仅浪费机场流量，还会导致国内网络奇卡无比。这就引出了 Quantumult X 最强大的功能：**分流规则 (Routing Rules)**。

### 1. 什么是分流规则？

分流规则就像是网络世界的“交通警察”。它通过读取您想要访问的网址（域名或 IP），并根据预设的规则表，指挥流量走不同的通道：
- **Direct (直连)**：访问百度、B站等国内网站时，不经过节点，直接连接。
- **Proxy (代理)**：访问 Google、Twitter 时，走您刚才添加的机场节点。
- **Reject (拒绝)**：访问各类广告联盟的网址时，直接拦截，实现去广告的效果。

### 2. 添加强大的“懒人规则集合” (Rule Set)

自己一条条写规则是不现实的。好在互联网上有众多开源的大神维护着极其完善的规则库（例如知名的 DivineEngine 神机规则、blackmatrix7 规则等）。新手只需引用这些规则集即可。

**操作步骤**：
1. 点击右下角 “大风车” -> 找到“分流”模块下的 **“规则资源 (Filter)”**。
2. 点击右上角的 **“+”**。
3. 同样，填入规则链接。这里提供几个极其常用且稳定的开源规则库链接供大家使用（您可以直接复制）：

   *   **去广告规则 (Reject)**:
       `https://raw.githubusercontent.com/blackmatrix7/ios_rule_script/master/rule/QuantumultX/Advertising/Advertising.list`
   *   **国际流媒体规则 (Proxy - 如 Netflix, Disney+)**:
       `https://raw.githubusercontent.com/blackmatrix7/ios_rule_script/master/rule/QuantumultX/GlobalMedia/GlobalMedia.list`
   *   **国内直连规则 (Direct)**:
       `https://raw.githubusercontent.com/blackmatrix7/ios_rule_script/master/rule/QuantumultX/China/China.list`

4. 添加时，系统会问您为这个规则集分配什么 **策略 (Policy)**。
   * 去广告规则 -> 选 **Reject**
   * 流媒体规则 -> 选 **您的机场节点组（或者 Proxy）**
   * 国内规则 -> 选 **Direct**
5. 保存后，您的圈X就拥有了智能大脑。

### 3. 理解策略组 (Policy) 的高级玩法
策略组是将多个节点打包在一起的管理方式。常用的策略组类型包括：
- **可用策略 (Available)**：将所有节点放进去，圈X会按顺序测试，哪个能连通就用哪个，适合作为备用方案。
- **延迟测试 (Url-Test)**：系统每隔一段时间测试节点延迟，自动为您切换到当前延迟最低（最快）的节点。这对于追求稳定刷网页的用户简直是神器！
- **按需选择 (Select)**：纯手动组，需要您自己在主界面点选想用的国家节点，通常用于有特定 IP 需求的场景（如登录某国特定的游戏区服）。

## 五、 高阶终极玩法：重写 (Rewrite) 与 MITM (中间人攻击) 配置详解


如果说分流规则是交通警察，那么 Rewrite 和 MITM 就是“网络魔术师”。它们不仅能阻挡请求，还能修改请求的内容。最典型的应用场景就是解锁某些 App 的会员界面、彻底屏蔽 YouTube 的片头广告、或者去除国内毒瘤 App 的开屏广告。

> *(注：此处主要讲解技术原理和配置步骤，具体去广告脚本需使用者根据开源社区指引获取)*

### 1. 什么是 MITM？为什么要安装证书？

绝大多数现代网站和 App 都使用了 HTTPS 加密传输。如果在没有授权的情况下，圈X无法看到加密流量里的具体内容，自然也就无法进行修改或去广告。
**MITM (Man-in-the-Middle，中间人)** 技术就是让圈X生成一个安全的本地证书。当您信任这个证书后，圈X就能解密您指定的网络请求，执行脚本修改后再重新加密发给服务器。这是实现高级去广告的关键。

### 2. MITM 证书安装教程（必做步骤）

这是新手最容易卡住的地方，请严格按以下步骤操作：

**步骤一：生成证书**
1. 打开圈X，点击右下角 “大风车”。
2. 向下滑动，找到 “MitM” 模块。
3. 点击 “生成证书 (Generate Certificate)”。

**步骤二：配置并安装证书**
1. 点击 “配置证书 (Configure Certificate)”。这时系统会自动跳转到 Safari 浏览器，并提示下载一个配置文件。点击“允许”。

**步骤三：在 iOS 系统中安装**
1. 退出圈X，打开 iPhone 自带的 **“设置”** App。
2. 点击顶部的 **“已下载描述文件 (Profile Downloaded)”**。
3. 点击右上角的“安装”，输入手机密码，一路安装到底。

**步骤四：信任证书（最关键的一步）**
1. 在 iPhone 的“设置”中，依次进入：**通用 -> 关于本机 -> 证书信任设置**（滑动到最底部）。
2. 找到名为 `Quantumult X Custom Root Certificate...` 的开关。
3. 将其打开（变成绿色），系统会弹出警告，点击“继续”。

**步骤五：开启 MitM 开关**
1. 回到 Quantumult X 的设置（大风车），将 MitM 模块右侧的开关打开。

### 3. 如何添加 Rewrite (重写) 脚本资源？
与添加分流规则非常类似：
1. 点击“大风车” -> 找到“重写”模块下的 **“引用 (URI)”**。
2. 粘贴开源大神提供的重写脚本链接（后缀通常是 `.conf` 或 `.snippet`）。
3. 保存后，确保您在第一步开启了 MitM，圈X就能根据脚本自动为您过滤各种 App 内置广告了！

## 六、 终极捷径：如何一键导入“懒人配置文件”？


如果您觉得上述分别添加节点、分流规则、重写脚本的过程太过繁琐，圈X 提供了一个终极的解决方案——**覆盖全局配置文件**。

许多大佬已经将他们调教完美的配置（包含了最好的规则、最好的脚本组合）写成了一个 `.conf` 文件。您只需要将这个文件的内容替换掉您本地的配置即可。

**操作步骤**：
1. 复制一份大佬提供的完整配置文件链接（如 Github 上的开源懒人配置 URL）。
2. 在圈X的“大风车”设置页，滑动到最底部的 **“配置文件 (Configuration)”** 区域。
3. 点击 **“下载 (Download)”**。
4. 将刚刚复制的 URL 粘贴进去，点击右上角的下载。
5. 系统会提示“是否保存并覆盖当前配置？”，选择 **保存**。

> **⚠️ 注意**：覆盖配置后，您的节点也会被清空。这时候，您只需要回到本文的【第三步】，重新将您的机场订阅链接导入进去，您就拥有了一个拥有顶级规则大脑+优质线路的完美圈X了！

## 七、 常见问题排障指南 (FAQ)

在使用过程中，新手不可避免会遇到一些小问题。以下是全网总结的最常见问题及解决办法：

### Q1: 节点全部显示 "Timeout"（超时），无法上网怎么办？
- **排查 1**：检查右上角的总开关是否打开。
- **排查 2**：检查您的机场订阅是否过期，或者流量是否耗尽（登录机场官网查看）。
- **排查 3**：如果是刚更新了订阅，可能是网络波动，尝试切换到另一个节点，或者重启一遍 Quantumult X。
- **排查 4**：尝试长按节点组，选择“全部 Ping 测试”，看看是否所有节点都死了。如果是，请联系您的机场客服。

### Q2: 为什么有些国内 App（如贴吧、淘宝）突然加载很慢甚至连不上？
- **原因**：这通常是因为分流规则没有正确配置，导致国内网站也走了国外代理节点。
- **解决**：检查您的分流规则是否包含 `China.list` 并将其指向了 `Direct`。如果懒得弄，可以在主界面的“分流模式”中心，临时切换为 **“全部直连”**。

### Q3: 开启 MITM 后，部分银行 App 或者支付宝提示网络不安全？
- **原因**：银行类 App 对证书非常敏感，如果检测到网络被“中间人”劫持（哪怕是我们自己为了去广告设置的），就会拒绝连接。
- **解决**：我们需要在 MitM 的主机名 (Hostname) 列表中，放行这些 App 的域名，或者直接在分流规则中将这些支付 App 的域名设置为 `Direct` 且跳过 MitM。
