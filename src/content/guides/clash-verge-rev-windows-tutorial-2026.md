## 三、 软件安装与基础初始化（界面汉化与内核设置）

### 第一步：安装软件
1. 双击下载好的 `.exe` 安装包。
2. 遇到 Windows Defender 拦截提示时，点击 **“更多信息”** -> **“仍要运行”**。
3. 按照提示点击“下一步”，建议安装在默认路径，并勾选“创建桌面快捷方式”。

### 第二步：切换为简体中文
第一次打开软件，界面可能是全英文的，我们需要将其汉化：
1. 点击左侧导航栏的 **「Settings」**（设置）。
2. 在主界面找到 **「Verge Setting」** 模块。
3. 找到 **「Language」**，点击下拉菜单，选择 **「简体中文」**。
4. 界面会瞬间完成汉化，无需重启软件。

### 第三步：确认内核版本（极其重要）
要让软件支持最新的机场节点协议，必须确保内核正确：
1. 继续在 **「设置」** 页面。
2. 找到 **「Clash 内核」** 选项。
3. 确保旁边的按钮高亮显示为 **「Mihomo」**（如果是 Alpha 则点击切换为 Mihomo），并点击后方的重启内核按钮，确保其在后台正常运作。

## 四、 核心操作：如何导入机场订阅链接？

客户端只是一个“空壳播放器”，要让它连上网络，你需要导入我们机场提供的“订阅链接（节点播单）”。

### 方式一：一键快速导入（最推荐，防出错）
1. 登录本机场的网站后台，进入 **「用户中心」**。
2. 找到 **「一键订阅」** 或 **「快速导入」** 区域。
3. 点击 **「导入到 Clash Verge」**（如果没有专门的 Verge 按钮，点击“导入到 Clash”即可）。
4. 此时浏览器会弹窗提示“是否允许打开此类型的链接？”，点击 **“允许”**。
5. Clash Verge Rev 软件会自动弹出，并在“订阅”界面自动开始下载配置文件。

### 方式二：手动复制订阅链接（备用方案）
如果一键导入没有反应，请使用手动导入方式：
1. 在机场后台，点击 **「复制 Clash 订阅链接」**。
2. 打开 Clash Verge Rev 软件，点击左侧菜单栏的 **「订阅 (Profiles)」**。
3. 在上方蓝色的输入框（URL栏）中，**粘贴**你刚才复制的订阅链接。
4. 点击右侧蓝色的 **「导入 (Import)」** 按钮。
5. 等待几秒钟，下方会出现一个带有节点数量和流量信息的长条形卡片。
6. **👉 注意：用鼠标左键点击一下这张卡片，让它的背景色变亮，出现一个 ✅ 的标志，代表该订阅已激活。**

## 五、 代理模式详解与节点选择

订阅导入成功后，我们还需要告诉软件“怎么用这些节点”。

### 1. 测速并选择节点
1. 点击左侧菜单栏的 **「代理 (Proxies)」**。
2. 展开 **「节点选择」** 或 **「PROXY」** 分组。
3. 点击右侧带有 ⚡（闪电）图标的测速按钮。
4. 等待几秒后，节点右侧会显示绿色的数字（如 `35ms`）。
5. 选择一个带有绿色延迟数字的节点（推荐香港、日本、新加坡等亚洲节点，延迟低、速度快）。

### 2. 切换代理模式（非常关键）
点击软件右上角的 **「代理模式」** 下拉菜单，你会看到三个选项，这是新手最容易踩坑的地方：

*   **规则模式 (Rule) - ⭐ 强烈推荐日常使用**
    *   **原理**：软件内置了一套智能分流规则。当你在浏览器访问国内网站（如百度、淘宝）时，流量直连，不消耗机场流量；当你访问海外网站（如 Google、YouTube）时，自动走代理节点。
    *   **优点**：兼顾速度与流量，国内外互不影响，挂机首选。
*   **全局模式 (Global) - 特殊场景使用**
    *   **原理**：电脑所有的流量强制走代理节点。
    *   **缺点**：访问国内网站会非常慢，甚至打不开，且极大浪费你的机场流量。仅在测试节点或某些特定海外网站无法用规则模式打开时临时使用。
*   **直连模式 (Direct) - 相当于关闭代理**
    *   **原理**：全部流量均不经过代理，等同于没开软件。

**👉 总结：请务必将代理模式保持在「规则 (Rule)」。**

### 3. 开启系统代理，正式起飞！
1. 回到左侧导航栏的 **「设置」**。
2. 找到首行的 **「系统代理 (System Proxy)」**。
3. 将右侧的开关拨到 **开启状态（变色）**。
4. 现在，打开浏览器，输入 `www.google.com` 或 `www.youtube.com`，享受极速冲浪吧！

## 六、 高阶必修课：TUN 虚拟网卡模式怎么开？

### 什么是 TUN 模式？为什么你需要它？
默认的“系统代理”模式只能接管浏览器的流量，但很多电脑软件是**不走系统代理**的！例如：
*   **命令行工具**：CMD、PowerShell、Git 终端。
*   **各类游戏**：Steam 外服游戏、Epic 平台。
*   **特殊应用**：Telegram 桌面版（未设内建代理时）、部分 UWP 微软商店应用、Discord 语音。

**TUN 模式** 会在你的 Windows 系统里虚拟出一张网卡，**强行接管电脑底层的所有网络流量**，实现真正的“真·全局路由分流”。

### TUN 模式开启步骤：
1. 关闭所有正在运行的代理软件和其他 VPN，以防冲突。
2. 打开 Clash Verge Rev，进入 **「设置」**。
3. 向下滚动，找到 **「服务模式 (Service Mode)」**，目前状态应该显示为未安装或红色的盾牌。
4. 点击右侧的 **「安装」**，系统可能会弹出用户账户控制 (UAC) 授权，点击 **「是」**。
5. 等待几秒钟，状态旁边会出现一个 **绿色的盾牌图标** 🛡️，代表服务安装成功。
6. 在服务模式下方，找到 **「TUN 模式 (Tun Mode)」**，将其开关 **开启**。
7. 此时，你的整台电脑已经完美接管，各类游戏和顽固软件均可畅通无阻！

*(提示：开启 TUN 模式后，你可以关闭顶部的“系统代理”，两者不需要同时开启，TUN 的优先级更高且更全面。)*

## 七、 常见问题与网络故障排错大全（FAQ）

在日常使用中，你可能会遇到一些突发状况。作为专业的机场博客，我们为您整理了最全面的排障指南，99% 的问题均可通过以下方式自行解决：

### Q1: 软件关闭后，电脑连不上网，显示“未连接到互联网”？
*   **原因**：这是 Windows 系统的通病。非正常关闭 Clash（如直接结束进程或闪退）导致系统的代理开关没有自动复位。
*   **解决方法**：
    1. 按键盘上的 `Win + i` 打开系统设置。
    2. 进入 **「网络和 Internet」** -> **「代理」**。
    3. 找到 **「使用代理服务器」**，将其手动关闭即可恢复正常上网。

### Q2: 导入订阅链接时报错“网络错误”或“Timeout”？
*   **排查步骤**：
    1. 检查订阅链接是否复制完整，前后不要有空格。
    2. 你的本地宽带可能屏蔽了机场的订阅域名。尝试在手机上使用流量开启热点，让电脑连上手机热点后再点击“更新订阅”。
    3. **检查电脑系统时间**：非常重要！如果你的 Windows 电脑时间与国际标准时间误差超过 2 分钟，SSL 证书握手就会失败，导致无法下载。请在系统设置中“同步时钟”。

### Q3: 为什么所有节点的延迟都显示 `Timeout` 或红色的 `-1`？
*   **排查步骤**：
    1. 首先确认你的机场套餐是否已经过期，或者本月流量是否已经耗尽（登录机场后台查看）。
    2. 尝试点击订阅卡片上的 **「更新」** 按钮，获取服务商最新的节点 IP（因为旧 IP 可能已被 GFW 封锁）。
    3. 如果是在公司局域网或校园网，可能是防火墙拦截了特定端口，建议开启 TUN 模式或联系机场客服寻求专线节点。

### Q4: 能够访问 Google，但无法观看 Netflix 或 ChatGPT 提示所在地区不可用？
*   **原因**：这并非软件问题，而是你选择的节点 IP 被这些平台拉黑了。
*   **解决方法**：回到 **「代理」** 界面，手动将节点切换到原生 IP 节点（通常机场会标注解锁流媒体/GPT，建议尝试新加坡或台湾节点），并在浏览器中使用隐身模式重新打开网页。

### Q5: 提示“端口冲突 (Port in use)”？
*   **原因**：你电脑上同时运行了其他代理软件（如 v2rayN、老版 CFW），占用了 7890 端口。
*   **解决方法**：完全退出其他代理软件，或者在 Verge 的“设置”中，将“混合端口 (Mixed Port)”修改为 `7891` 或其他数字，然后重启应用。

4. 右键应用于你的机场订阅，即可在不修改原订阅的情况下，实现个性化的流量路由策略。
