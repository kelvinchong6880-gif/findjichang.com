## 三、 核心操作：V2rayNG 添加节点的 3 种方式

软件安装完毕后打开，初始界面是一片空白。我们需要为它添加节点信息。根据您的数据来源，有以下三种方式：

### 方式一：导入机场订阅链接（最推荐、批量导入）

这是绝大多数使用翻墙机场服务的用户的标准操作，能够一次性同步几十上百个全球节点并支持自动更新。
### 1. 获取订阅登录您的机场后台，找到“一键订阅 / 复制订阅”区域，点击 **“复制 V2Ray 订阅链接”** 或 **“复制通用订阅”**。

### 2. 创建订阅分组打开 V2rayNG，点击左上角的 **“三条横杠 (菜单栏)”**。

3. 选择 **“订阅分组设置”**。
4. 点击右上角的 **“+ (添加)”** 图标。
### 5. 填写订阅信息

   *   **备注 (Name)**：填写您机场的名字（如“主力高速专线”）。
   *   **可选地址 (URL)**：长按输入框，粘贴刚刚从机场后台复制的订阅链接。
   *   点击右上角的 **“✓ (保存)”**。
### 6. 拉取节点返回 V2rayNG 主界面。点击右上角的 **“三个点 (更多选项)”**。选择 **“更新订阅”**。稍等片刻，主页面就会整齐刷出香港、日本、新加坡、美国等各地的所有节点。


### 方式二：扫描屏幕二维码导入

如果您在电脑网页上购买了节点，或者朋友的手机上有节点二维码：
1. 打开 V2rayNG 主界面，点击右上角的 **“+ (添加)”** 图标。
2. 选择 **“扫描二维码”**。
3. 允许相机权限，对准屏幕上的二维码扫描，节点便会瞬间秒添加到列表底部。

### 方式三：从剪贴板直接导入

如果您在 Telegram、微信等聊天软件中复制了一串以 `vmess://`、`vless://`、`ss://` 或 `trojan://` 开头的单节点字符串：
1. 复制整段链接。
2. 打开 V2rayNG，点击右上角 **“+”** 号。
3. 选择 **“从剪贴板导入”**，软件会自动识别解析并生成节点。

## 四、 节点测速、切换与开启代理

节点导入成功后，我们即可开始连接网络。

### 1. 真实可用性测速 (Real Delay Ping)
在连接前，强烈建议先测试哪些节点可以正常连通：
1. 点击右上角 **“三个点”**。
2. 选择 **“测试全部配置真实连接”**（或者点击底部右侧的批量测试按钮）。
3. 软件会向目标服务器发送 HTTP 请求：
   *   **显示绿色数字**（如 `120ms`）：表示该节点状态良好、网络畅通。
   *   **显示红字**“`Timeout / 超时`”或“`-1ms`”：表示节点暂时失效或网络被阻断，请勿选择。

### 2. 选中节点并启动
1. 在节点列表中，点击您想要使用的节点（选中后该节点卡片左侧会出现一条明显的竖色标线表示激活）。
2. 点击右下角巨大的 **“V 字型圆形启动图标”**。
3. 首次开启时，系统会弹出系统底层的 VPN 连接确认窗口：“V2rayNG 想要设置一个 VPN 连接”，点击 **“确定 / 允许”**。
4. 此时 V 字图标变为深色/亮色，顶部状态栏出现 VPN 钥匙图标，代表代理已成功建立！您可以打开浏览器访问 Google、YouTube 验证连接。

## 五、 智能上网核心：路由分流设置（告别卡顿与浪费流量）


如果开启了全局代理，国内的 App（如淘宝、微信、高德地图）也会绕道国外服务器，这会导致定位漂移、打开奇慢甚至浪费机场宝贵的套餐流量。配置“路由分流”是必做步骤。

### 1. 开启“绕过局域网及大陆地址”
1. 点击左上角 **“三条横杠 (菜单)” -> 进入 “设置”**。
2. 找到 **“路由设置”** 板块下的 **“预定义规则”**（或自定义路由）。
3. 选择 **“绕过局域网及大陆地址 (Bypass LAN and mainland China)”**。
   *   **工作原理**：当您访问国内网站和局域网设备时，流量直接走手机物理网络（高速且不消耗节点流量）；只有访问被阻断的海外网站时，才会将数据包交给代理节点加密转发。

### 2. 域名解析策略 (Domain Strategy) 建议
在设置中，将 **“域名解析策略”** 设置为 **“IPIfNonMatch”** 或 **“AsIs”**：
- **IPIfNonMatch**：优先使用域名分流规则匹配；如果未命中，则将域名解析为 IP 地址后再进行第二次地域分流判断。这是最稳妥、防 DNS 污染的最佳设置。

## 六、 进阶极客技巧：分应用代理 (Per-App Proxy)

很多用户在开着代理时，登录中国建设银行、招商银行等手机银行或者国税 App 会被安全系统警告。V2rayNG 原生支持分应用代理，用于解决该问题。

**设置步骤**：
1. 打开左侧菜单 -> 进入 **“设置”**。
2. 找到并点击 **“分应用代理”**。
3. 将最上方的 **“开启分应用代理”** 开关打开。
4. 点击右上角“三个点”，建议选择 **“仅允许已选择的应用”**（白名单机制）：
   *   在应用列表中勾选需要翻墙的应用，如：Google Chrome, YouTube, X (Twitter), Telegram, Netflix, Instagram, ChatGPT, Gmail 等。
5. 设置完成后返回。此时除了勾选的这几个软件，手机上的微信、支付宝、网银 App 将完全不经过 V2rayNG，直连无阻碍。

## 七、 常见问题与排障指南 (FAQ)

### Q1: 节点测试有延迟（显示 200ms），但连上后依然打不开网页？

- **原因 1**：手机系统时间与标准时间不同步。V2Ray/VMess 协议对时间戳校验极高，若手机时间误差超过 90 秒，服务器会直接拒绝握手。
    *   **解决办法**：前往手机“设置 -> 系统时间”，开启“自动同步网络时间”。
- **原因 2**：DNS 污染或配置冲突。
    *   **解决办法**：进入 V2rayNG 设置，将“本地 DNS”恢复默认，或关闭系统自带的“私密 DNS (Private DNS)”。

### Q2: 订阅更新失败，提示 “Update subscription failed / SSL handshake failed”？

- **解决 1**：检查复制的订阅链接是否有头尾空格。
- **解决 2**：部分机场订阅服务器在未翻墙状态下无法直连。您可以先连上一个可用的免费节点或临时节点，开启代理后再点击“更新订阅”。
- **解决 3**：登录机场官网，确认套餐未过期且流量未用尽。

### Q3: 锁屏一段时间后自动断开，打开屏幕又恢复？
- **原因**：国产手机系统（MIUI、OriginOS、ColorOS、鸿蒙等）自带激进的省电策略杀死了后台进程。
- **解决**：在手机“应用设置”中找到 V2rayNG，将“电池优化”改为 **“无限制 / 不优化”**，并在多任务切换界面对 V2rayNG 下拉加锁。
