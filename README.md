## 买机场前的 5 个建议

1. **先月付**：第一次买先买一个月，在自己的网络里试过晚高峰再考虑年付。
2. **看折合月价**：年付通常更便宜，但流量按月重置，用不完不累计。
3. **看倍率**：部分机场节点有流量倍率，实际可用流量要除以倍率。
4. **看解锁**：要用 ChatGPT 或看 Netflix，先确认节点地区与解锁说明。
5. **留备用**：主力机场之外，留一个小流量或不限时流量包防失联。
